Flower Gods

以十二月令花神为主题，将人物海报、瓶贴包装、国风馆空间效果和落地应用整理成一套可传播、可延展、可进入线下场景的国风视觉系统。

Visual System 01

十二花神系列视觉系统

这一组不是单独的海报、瓶贴或空间图，而是一套围绕“十二月令花神 + 城市花卉延展”展开的主题视觉物料：人物海报建立 IP 角色，瓶贴承接文创产品，国风馆完成线下空间落地，蓝花楹继续延展为城市限定活动传播。

Project Type

国风主题视觉 / 人物海报系统 / 文创包装与空间落地。

My Role

主题策划、角色视觉统一、海报排版、瓶贴延展、空间应用整理。

Output

十二花神人物海报、集合海报、瓶贴、瓶贴效果图、国风馆效果图与落地图。

Value

从单张人物视觉扩展到活动宣发和文创场景，适配文化 IP、城市活动与新媒体专题。

主题总览

主题总览

招聘者第一眼需要看到“这是一整套项目”。这里先放集合海报和空间落地，把主题、角色数量和应用场景一次性交代清楚。

海报设计延展

月令人物海报

人物海报按月份排列，展示同一视觉母题下的角色差异：花材、人物状态、色彩和版式保持统一，但每一张都有独立记忆点。

包装设计延展

瓶贴包装延展

把花神角色从海报延展到瓶贴包装，补足“视觉系统能否应用到真实产品”的证据。后续可以继续增加材质、尺寸和打样说明。

空间落地应用

国风馆落地应用

线下效果图和落地图能直接回应招聘方关心的执行问题：视觉不只停在屏幕里，也可以进入展陈、活动现场和品牌空间。

城市花卉延展

蓝花楹城市延展

蓝花楹作为城市花卉延展，适合后续包装成“城市限定角色”或社媒专题视觉，让系列不止停在十二月令。

06 / Live Campaign Visuals

玩美了直播物料

第二套物料以直播传播和现场搭建为主，顺序按内容从线上预热视频/贴片到直播间与线下现场落地展开，展示活动视觉在多触点中的统一执行。
